# ReliefLink — Web-Based Disaster Relief & Emergency Coordination Platform 🌍🤝

ReliefLink is a full-stack disaster management web application developed using React, Vite, Node.js, Express.js, and MongoDB. The platform is designed to simplify disaster response by connecting affected people, volunteers, and NGOs/Relief Centers through a single centralized system.

---

## 🚀 Project Overview

ReliefLink helps coordinate emergency response by allowing users to send SOS requests, request relief materials, locate nearby relief camps, receive disaster alerts, and track requests in real time. NGOs coordinate rescue operations, manage inventories, assign volunteers, and monitor relief distribution through a centralized dashboard.

### Tech Stack

- **Frontend:** React.js (Vite), Vanilla CSS (Custom Utility System), Zustand, Leaflet.js
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT & Phone OTP Verification

---

## 👥 User Roles

| Role | Login Method | Features |
|------|--------------|----------|
| **Affected Person** | Phone Number OTP | SOS, Relief Requests, Camp Finder, Weather Updates |
| **Volunteer** | Email & Password | Rescue Tasks, Delivery Tasks, Navigation, Task Updates |
| **NGO / Relief Center** | Email & Password | Inventory, Camp Management, Volunteer Management, Reports |
